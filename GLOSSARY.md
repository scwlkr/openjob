# Glossary

**Connected source Mail**: a Task's provider message, fetched only while its original
Workspace and connection remain authorized. Private references are kept separately
from ordinary Task/Calendar data. A source link does not grant Mail access.

**Retained Personal context**: a stable Workspace reference to existing Personal
Tasks and Calendar, without copying or changing their underlying ownership.

Existing Task and release terms remain in [CONTEXT.md](CONTEXT.md).
